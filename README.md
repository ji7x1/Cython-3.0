# سايثون Cython 3.0

**سايثون** مساعد ذكي يحجي باللهجة **العراقية (البغدادية)**، مشروع تخرج لطلاب الهندسة في الجامعة التكنولوجية (UOT):
**Ahmed Zaher** و **Ali Qutaiba**.

النسخة 3.0 تربط واجهة التطبيق (الدردشة، الملاحظات، المهام، المؤقت، الألعاب، الخزنة...) بسيرفر حقيقي مبني بـ **FastAPI**،
والردود تجي من موديل **Llama 3.3 70B** عن طريق **Groq** و **LangChain**، ويه شخصية سايثون العراقية.

## شنو الجديد بـ 3.0

- الدردشة صارت حقيقية: `chat.html` يرسل للسيرفر (`POST /chat`) بدل الرد الوهمي، ويه مؤشر "دا يكتب" ورسائل خطأ باللهجة العراقية.
- **ذاكرة للمحادثة**: سايثون يتذكر آخر الرسائل بنفس المحادثة (`conversation_id`).
- أمر واحد يشغل كلشي: السيرفر يقدم صفحات الواجهة والـ API سوية.
- السيرفر ما يوكع إذا المفتاح ناقص، و `/chat` يرجع خطأ واضح (503) بدل ما يطفي.
- عرض الرسائل آمن (ماكو `innerHTML` لنص المستخدم أو الموديل).
- كود الثيم المكرر بالصفحات انتقل لـ `style.css` و `script.js` بدون ما يتغير الشكل.
- اختبارات `pytest` للسيرفر، والموديل مزيّف بيها (ما تحتاج إنترنت ولا مفتاح).

## التشغيل على جهازك

تحتاج **Python 3.10 أو أحدث**.

```bash
# 1. بيئة افتراضية وتنصيب المكتبات
python -m venv .venv
source .venv/bin/activate          # بالويندوز: .venv\Scripts\activate
pip install -r requirements.txt

# 2. المفتاح السري
cp .env.example .env               # بالويندوز: copy .env.example .env
# افتح .env وحط مفتاحك: GROQ_API_KEY=...   (تاخذه من https://console.groq.com/keys)

# 3. تشغيل كلشي بأمر واحد
python -m backend
```

بعدها افتح المتصفح على: **http://127.0.0.1:8000**

- الصفحة الرئيسية: `/` (index.html)، الدردشة: `/chat.html`
- فحص السيرفر: `/health`
- توثيق الـ API التلقائي: `/docs`

> إذا شغلت السيرفر بدون مفتاح، الصفحات كلها تشتغل بس الدردشة تطلعلك رسالة إن سايثون مو مربوط بالذكاء الاصطناعي.

للتطوير ويه إعادة تحميل تلقائي: `RELOAD=true python -m backend`
أو مباشرة: `uvicorn backend.main:app --reload`

### الاختبارات

```bash
pip install -r requirements-dev.txt
```

## الـ API باختصار

| الطلب | الوصف |
|---|---|
| `GET /health` | حالة السيرفر: `{"status": "ok", "version": "3.0.0", "llm_configured": true}` |
| `POST /chat` | يرسل `{"message": "...", "conversation_id": "اختياري"}` ويرجع `{"reply": "...", "conversation_id": "..."}` |
| `DELETE /chat/{conversation_id}` | يمسح ذاكرة المحادثة |

أكواد الأخطاء من `/chat`:

| الكود | المعنى |
|---|---|
| `422` | الرسالة فارغة أو أطول من 4000 حرف، أو `conversation_id` مو صحيح |
| `429` | مزود الموديل (Groq) دا يرفض لأن الطلبات هواية |
| `503` | `GROQ_API_KEY` ناقص أو مرفوض |
| `504` | الموديل طوّل بالجواب |
| `502` | خطأ ثاني من مزود الموديل |

## الإعدادات (`.env`)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `GROQ_API_KEY` | — | مفتاح Groq (مطلوب للدردشة) |
| `GROQ_MODEL` | `llama-3.3-70b-versatile` | اسم الموديل |
| `MAX_HISTORY_MESSAGES` | `20` | كم رسالة أخيرة يتذكر سايثون بكل محادثة |
| `MAX_CONVERSATIONS` | `1000` | أقصى عدد محادثات بالذاكرة (الأقدم ينمسح) |
| `LLM_TIMEOUT_SECONDS` | `30` | مهلة طلب الموديل |
| `CORS_ORIGINS` | `localhost:8000` و `localhost:5500` | المواقع المسموح لها تكلم الـ API من دومين ثاني |
| `HOST` / `PORT` | `127.0.0.1` / `8000` | عنوان التشغيل |

> الذاكرة حالياً بالـ RAM، يعني تنمسح إذا انطفى السيرفر.
